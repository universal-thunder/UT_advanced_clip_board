# 高级剪贴板 · AdvancedClipboard

Windows 十槽复制与剪切工具。为内容命名，通过快捷键按编号粘贴，在一个窗口里管理文件、文字和图片。

**系统：Windows 10/11 x64。测试版：0.1.0-beta。** 程序自带 .NET 10 桌面运行环境，无需安装开发环境；不添加右键菜单、不随开机启动。槽位仅保存在内存中，退出、注销或关机后清空。

## 下载与开始使用

打开本仓库 **Releases**，下载以下任一种附件：

- `AdvancedClipboard-Setup-v0.1.0-beta-win-x64.exe`：离线安装器。选择程序安装位置和快捷方式文件夹，安装后可在 Windows 已安装应用中卸载。
- `AdvancedClipboard-v0.1.0-beta-win-x64-portable.zip`：便携版。全部解压，双击 `AdvancedClipboard.exe`。保留完整文件夹，不能只拿走 EXE。

`Code → Download ZIP` 和 `Source code (zip)` 是源码，通常不能双击使用。安装器无需联网下载主体，也不要求管理员权限。首次发布尚未数字签名，Windows 可能提示未知发布者；请确认下载来源。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Shift+C | 高级复制，随后命名 |
| Ctrl+Shift+X | 高级剪切，随后命名 |
| Ctrl+Shift+V | 选择槽位粘贴，可多选兼容内容 |
| Ctrl+Shift+B | 查看、删除、重命名和整理槽位 |
| Ctrl+Shift+1…9 | 直接粘贴相应槽位 |
| Ctrl+Shift+0 | 直接粘贴第 10 槽 |

选中内容 → 高级复制 → 回车接受槽号或输入名称 → 在目标位置高级粘贴。命名和选择窗口置顶。文件粘贴到桌面时，可以在选择窗口勾选“粘贴到桌面”。

## 槽位规则

- 最多 10 槽，先分配空槽；满槽时经确认替换第 10 槽。
- 名称不能为空，不能与已有槽位重名。
- 复制槽保留；剪切槽完成粘贴后释放。
- 文本多选按槽号合并；文件可多选；不同大类内容不能混合粘贴。
- 文件重名复制生成 `原名-副本（n）.扩展名`。剪切移动遵循文件冲突提示。
- 右上角关闭按钮和“关闭程序”会真正退出；有内容时提示确认。

## 使用边界

支持常见文件、文件夹、文件组、纯文本、富文本、网页文本、网址、图片和常见表格文本。**并非所有软件或格式都适用**：

- 专用剪贴板格式、受保护窗口、管理员窗口和游戏可能不兼容。
- 部分快捷键会与浏览器、开发工具冲突，冲突时会提示；本版尚不支持自定义快捷键。
- 普通剪贴板是传递内容的临时桥梁；程序尽量保存和恢复常见格式，不保证所有软件专有数据原样恢复。
- 非文件粘贴依靠标准 Ctrl+V，无法可靠判断每个目标软件是否实际接收。重要内容建议优先复制，剪切前保留备份。
- 文件槽保存路径而非备份，原文件被移动或删除后可能失效。
- 无法自动识别目标位置时，应先激活正确窗口；桌面文件粘贴可以使用显式勾选项。

## 开发与打包

需要 Windows 和 .NET 10 SDK。运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

生成的安装器、便携 ZIP 和 SHA256 校验文件在 `artifacts/dist/`。脚本先发布自带运行时版本，运行程序自检，构建离线安装器，再验证解包、文件校验、快捷方式与卸载。

```text
src/AdvancedClipboard/   主程序源码与项目配置
installer/              安装器、卸载器与安装测试源码
scripts/                可复现构建脚本
docs/                   使用、隐私、发布与检查记录
third-party/            随附 .NET 运行时许可与声明
.github/workflows/      Windows 自动构建
LICENSE                 MIT 许可证
```

构建和贡献说明见 [CONTRIBUTING.md](CONTRIBUTING.md)。欢迎提交可复现的错误报告，注明系统版本、目标软件、快捷键和操作步骤，避免上传敏感剪贴板内容。
