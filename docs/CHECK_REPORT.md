# 本轮检查记录

日期：2026-09-17。版本：0.1.0-beta。

## 主程序

检查了槽位管理、内容分类、复制/剪切桥接、文件传输、关闭退出、单实例通信和安装注册边界。

确认并修复一处缺陷：自动名称在整理槽位时可能与自定义数字名称冲突。现在先完成槽位移动，再检查名称唯一性，仅在不冲突时更新自动编号；加入了相应回归自检。其余核心复制粘贴流程没有重写。

自检通过：SendInput 结构大小、URL/表格/纯文本/文件类型分类、文件复制、同目录及重名副本编号、槽位整理与名称冲突、兼容内容多选限制。

## 安装器

构建环境：Windows x64，.NET SDK 10.0.300，自带运行时 10.0.8。构建脚本在 Windows PowerShell 5.1 执行成功。

测试通过：

- 安装器窗口可正常初始化、响应和关闭。
- 程序主体和运行环境从嵌入 ZIP 解出，全部文件 SHA256 与原件一致。
- 安装后的主程序自检通过。
- 在测试目录成功创建快捷方式，卸载时清理对应快捷方式。
- 清单路径不能跳出安装目录。
- 模拟解包失败后回滚所写文件及空目录。
- 卸载删除安装清单记录的文件，保留用户自行添加的文件。

安装测试使用独立的项目内临时目录，完成后清理；没有替换或重启用户当前运行的主程序，也没有清空其槽位。

## 尚未覆盖

沙盒环境内没有实测 Windows 当前用户卸载登记；注册表安装与卸载操作已实现，但需要正常用户环境验证。没有在另一台未安装 .NET 10 的干净电脑完成端到端验收。没有为每一个第三方目标软件逐一测试复制剪切粘贴。

因此首版标为 beta，而不是宣称所有软件和电脑均可靠。本次源码结构整理和安装器构建，不解决专有剪贴板格式、模拟按键接收确认、快捷键冲突等现有边界，详见 README。
