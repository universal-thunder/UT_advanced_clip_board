# 0.1.0-beta

首次公开测试版。十槽命名复制/剪切、按编号直接粘贴、兼容内容多选、置顶命名与选择窗口、显式桌面文件粘贴、重名副本编号和槽位管理。

程序自带 .NET 10 Windows x64 运行时；提供离线安装器与便携 ZIP。安装器支持安装位置和快捷方式目录选择、可取消快捷方式，登记当前用户卸载入口。

不随开机启动，不注册右键菜单。窗口关闭真正退出；单实例通信按 Windows 账号和会话隔离。

本轮仅修复“整理槽位可能造成自动名称与自定义名称重复”的确认缺陷，其余主要交互保持原样。

## 已知限制

尚未在独立干净电脑完成验证，因此发布为 beta。无数字签名、自动更新、自定义快捷键或持久槽位。专用剪贴板格式和目标软件接收确认不保证支持。测试版安装到空目录；升级需先卸载。
