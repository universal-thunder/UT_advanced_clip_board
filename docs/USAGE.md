# 使用与安装

## 安装版

下载 Setup.exe，先关闭旧程序，然后选择独立安装文件夹。浏览选择一个父文件夹时，会默认添加 AdvancedClipboard 子文件夹。安装位置不是下载位置；例如安装到 D:\Apps\AdvancedClipboard。

快捷方式默认放在 Windows 实际桌面，也可以浏览到其他已存在文件夹，或取消创建。若存在同名快捷方式，替换前会询问。安装不注册右键菜单，不启用开机启动，也不需要管理员权限。

安装成功后，可从快捷方式或安装目录启动。卸载使用 Windows 设置中的“已安装应用”或安装目录中的 Uninstall.exe。先关闭程序；退出会清空槽位。升级本测试版请先卸载再安装，安装器拒绝覆盖非空目录。

## 便携版

完整解压并启动 AdvancedClipboard.exe。自带运行环境，不需要另装 .NET 10。运行时文件必须与 EXE 一起保留。便携版不提供系统卸载登记，关闭后可以删除整个解压文件夹。

## 复制、剪切和粘贴

在支持标准复制的地方选中内容，按 Ctrl+Shift+C。必须命名，可回车接受编号。剪切用 Ctrl+Shift+X；重要资料建议先复制以避免目标软件拒绝粘贴。

切换到目标窗口，按 Ctrl+Shift+V 选择内容，再点击“粘贴”。文件粘贴到桌面可勾选“粘贴到桌面”。此选项不适用于文字或图片本身。按 Ctrl+Shift+1…9 或 0，可直接粘贴对应槽位。

Ctrl+Shift+B 打开管理窗口，可删除所选、清空全部、整理槽位与重命名。“整理槽位”将剩余内容移到前方；自动编号名称只在不会与自定义名称冲突时更新。

退出后所有槽位清空。文件槽保存的是原文件路径，不能代替备份。槽位显示“来源失效”时，请重新复制原文件。

## 常见问题

- 快捷键占用：先关闭占用快捷键的软件，本版尚无自定义快捷键设置。
- 文件无法粘贴：检查源文件是否存在、目标目录是否可写；桌面场景使用勾选项。
- 软件专用对象无法复制：本版仅覆盖常见剪贴板格式，可使用该软件原生复制粘贴。
- 程序已运行：再次启动应唤起原窗口；若异常，可在任务管理器结束 AdvancedClipboard 后重试，槽位会清空。
- Windows 未知发布者提示：安装器目前未签名，应核实来源并用 SHA256 文件验证下载完整性。
