# 隐私与数据

- 程序与离线安装器没有设计上传剪贴板内容或联网下载的功能。
- 十个槽位只存内存；退出、注销、关机后清空，当前不持久保存。
- 文件槽保存文件路径，不复制一份备份到内部数据库。
- 普通系统剪贴板会被临时用于传递内容，随后尝试恢复支持的原始格式；不保证所有专用格式完整恢复。
- 槽位内容不是加密保险箱，也无法防止其他进程读取系统剪贴板。谨慎处理密码和个人资料。
- 粘贴失败可能在程序目录写入 paste-diagnostics.log，其中含时间、窗口类别和异常信息，异常可能包含文件路径。分享日志前请检查敏感路径；安装包不包含你电脑上的已有日志。
- 安装器仅登记当前用户的卸载信息并按选择建立快捷方式，不创建开机启动或资源管理器右键菜单。
